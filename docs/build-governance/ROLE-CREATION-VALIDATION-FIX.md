# عقد بناء — إصلاح إرشاد إنشاء الدور

**البصمة:** `4866d2f9` · الإدارة والصلاحيات · 2026-09-05
**المرجع المعماري:** `BASEER-ARCH v1.0`، وسجل الأثر `2026-09-05-role-creation-validation-feedback.md`.

## G0 — الفهم والنطاق

- **المستخدم والمشكلة:** مالك النظام يحاول إضافة دور من الجوال؛ النموذج يرد «تحقق من الحقول المطلوبة» في الأسفل بلا تحديد مفيد للحقول الناقصة.
- **القبول:** تظهر رسالة عربية/إنجليزية تشرح المتطلبات؛ يبقى خطأ كل حقل بجواره؛ بعد إرسال غير صالح ينتقل العرض إلى أول خطأ؛ لا يُرسل طلب إنشاء قبل اكتمال الحقول.
- **خارج النطاق:** لا تغيير في كتالوج الصلاحيات أو تخويل الخادم أو البيانات أو الأدوار الموجودة.
- **الحالة:** معتمد لهذا الإصلاح الواجهاتي المحدود.

## G1–G3 — السعة والعقود والتقنية

- لا قراءة كبيرة أو عملية خلفية أو بيانات أو مكتبة جديدة. لا يتغير عقد `POST /administration/roles` أو تحقق الخادم أو منع التكرار.
- المسار المباشر: إصلاح نموذج الواجهة القائم ومكوّن التحقق المشترك، بدلاً من إضافة مكتبة أو منطق إنشاء موازٍ.
- **الحالة:** معتمدة؛ لا تأثير على السعة أو مصدر الحقيقة أو التزامن.

## G4–G5 — التجربة والتنفيذ والتحقق

- تستخدم الرحلة مكوّنات Baseer الحالية (`BaseerTextInput` و`BaseerCheckbox` و`BaseerButton`) وتبقى RTL/LTR ومتجاوبة.
- التحقق المطلوب: فحص TypeScript للويب، و`check:web-localization`، ثم فحص فرق التغيير.
- **الحالة:** قيد التنفيذ.
