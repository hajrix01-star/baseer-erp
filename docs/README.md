# دليل وثائق Baseer ERP

## المرجع الحالي المختصر

هذه الملفات هي المرجع عند بدء العمل أو اتخاذ قرار جديد:

1. [ملخص التسليم](../BASEER_ERP_HANDOFF.md) — صورة تشغيلية مختصرة للمطور أو المراجع الجديد.
2. [سلطة التسليم الحالية](governance/CURRENT_DELIVERY_AUTHORITY.md) — النطاق النشط، الأولوية، وما هو محظور قبل إغلاق البوابات.
3. [سجل تسليم الموديولات](governance/MODULE_DELIVERY_REGISTER.md) — حالة كل موديول وحدوده.
4. [سجل أدلة الجودة](governance/QUALITY_EVIDENCE_AND_COMMITTEE_REGISTER.md) — الفحوص المنفذة والبوابات المفتوحة.
5. [معيار قراءة المالية والتوسع والفترات](governance/FINANCIAL_READ_SCALE_AND_PERIOD_STANDARD_2026-08-18.md) — قواعد الفترة، الصفحات، الإسقاطات، وحدود ادعاء الأداء.
6. [سياسة المصدر المالي والحقيقي](governance/FINANCIAL_AND_FACTUAL_SOURCE_OF_TRUTH_POLICY_2026-08-15.md) — ما الذي يملك الحقيقة المحاسبية.

## كيف نقرأ بقية الوثائق

- `governance/`: معايير دائمة، بوابات جودة، وسجلات القرار.
- `foundation/`: قرارات نطاق وتنفيذ مؤرخة للشرائح المالية والتشغيلية.
- `architecture/`: حدود الموديولات، المعمارية، ومقارنات Noorix.
- `migration/`: خرائط Noorix، الاستكشاف، وبوابات الترحيل. لا يعني وجودها أن الاستيراد منفذ.
- `operations/`: قرارات الاستضافة والتشغيل والنسخ والاستعادة.
- `identity/` و`marketing/`: قرارات المجالات الخاصة بها.

## سياسة الدمج وعدم التكرار

لا نحذف قراراً مؤرخاً أو دليلاً تاريخياً لمجرد أنه لم يعد الخطة الحالية؛ فهو يثبت لماذا اتُخذ القرار وحدوده في وقته. بدلاً من ذلك:

- الملفات الستة أعلاه هي **مصدر الحالة الحالية** ولا تنافسها وثيقة تاريخية.
- تقارير اليوم الواحد وقرارات Gate A/B تبقى سجلات تاريخية، ويُشار إليها من السجل الحالي عند الحاجة.
- لا يُنشأ ملف حالة جديد إذا أمكن تحديث سلطة التسليم أو سجل الموديولات أو سجل الجودة.
- أي وثيقة قديمة تُستبدل بإعادة كتابة في مكانها أو تُوسم صراحةً كسجل تاريخي؛ لا نترك ملخصاً قديماً يدّعي أنه الحالة الحالية.
