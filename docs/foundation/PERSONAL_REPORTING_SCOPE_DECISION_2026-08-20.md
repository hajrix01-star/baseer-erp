# Baseer ERP — قرار نطاق التقارير للاستخدام الشخصي

**الحالة:** معتمد من المالك وقابل للتغيير بقرار لاحق.
**التاريخ:** 2026-08-20
**النطاق:** هذه الشركة والاستخدام الشخصي الحالي فقط.

## القرار

لا يحتاج المالك إلى تقرير **ربح وخسارة استحقاقي** أو **قائمة مركز مالي/ميزانية عمومية دفترّية رسمية**، ولا يُبنى لأيٍّ منهما API أو كتالوج أو واجهة أو مخرج في النطاق الحالي.

التقرير المالي المعتمد للاستخدام اليومي هو **الربح والخسارة المالي**: كل مبلغ دخل أو خرج فعلياً عبر خزائن الشركة وبنوكها وتطبيقاتها، مع استثناء التحويلات الداخلية بين خزائن الشركة. وهو تقرير إداري غير استحقاقي، ولا يسمى قائمة ربح وخسارة رسمية.

## ما يبقى ولا يتغير

- لا تتغير القيود المحاسبية المختومة أو سياسة الرواتب والسلف أو ميزان المراجعة.
- تبقى بنية خريطة P&L versioned وسياسة R0-A محفوظتين كقدرة مستقبلية غير مفعّلة؛ لا تُحذف ولا تُعرض للمستخدم.
- قائمة المركز المالي تعامل كتقرير دفترّي رسمي، مثل الربح والخسارة الاستحقاقي: تحتاج خريطة عرض حسابات ذات إصدار، وسياسة للأصول والالتزامات وحقوق الملكية والأرباح المبقاة، ولقطة دفتر تاريخية قبل أن تُبنى.
- لا يعني هذا القرار ادعاء امتثال IFRS أو VAT أو تغيير أي التزام قانوني. أي حاجة نظامية مستقبلية تُراجع مستقلة.

## قابلية المراجعة

يجوز للمالك تغيير هذا القرار لاحقاً. عندها يبدأ العمل من اعتماد سياسة عرض وخريطة حسابات وإصدار تقرير جديد؛ ولا يعاد توصيف أو تعديل نتائج الربح والخسارة المالي أو القيود التاريخية.
