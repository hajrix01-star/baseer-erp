# معيار الحوارات في واجهة BASEER

## القرار

كل نافذة تحريرية تستخدم **زر × واحداً في رأس النافذة** للإغلاق. لا يظهر معه زر نصي آخر باسم «إغلاق» أو «إلغاء» داخل التذييل أو المحتوى.

## التذييل

- يحتوي التذييل على زر الإجراء الأساسي فقط: مثل «حفظ التغييرات» أو «إنشاء الشركة».
- تجمع الحقول العادية في عملية حفظ واحدة؛ لا يخصص زر حفظ لكل حقل أو جزء من النموذج.
- العمليات المستقلة ذات الأثر الخاص، مثل تعطيل مستخدم أو أرشفة شركة، تبقى أزراراً منفصلة ومسمّاة بوضوح.
- تعرض النافذة زر × دائماً، وتدعم مفتاح Escape؛ لا يغلق زر × أثناء الحفظ.

## الاستثناء

تستخدم نافذة العرض فقط زر × بلا تذييل. أما أي إلغاء لعملية مدمرة فيكون داخل تأكيد منفصل، وليس زر إغلاق مكرراً.

## ضمان الاستمرار

يفحص أمر `npm run check:web-dialog-conventions` حوارات React التي تستخدم `dialog-icon-button` ويمنع تكرار زر «إغلاق» أو «إلغاء» النصي داخل الحوار نفسه. يضاف الفحص إلى CI.
