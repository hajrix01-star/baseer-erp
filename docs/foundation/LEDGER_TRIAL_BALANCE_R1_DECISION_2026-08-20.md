# ميزان المراجعة الدفتري — R1

**الحالة:** منفذ محلياً كأول تقرير محاسبي للقراءة فقط؛ لا يتضمن طباعة أو Excel في هذه المرحلة.

## الهدف

يعرض ميزان المراجعة لكل حساب مؤهل: الرصيد الافتتاحي مدين/دائن، وحركة الفترة مدين/دائن، والرصيد الختامي مدين/دائن. هو تقرير دفتر من القيود المختومة، وليس تقرير تحصيل ومدفوعات فعلية ولا قائمة أرباح وخسائر؛ لا يقدّم ادعاء امتثال أو أساس مالي أوسع من مصدره.

## المصدر واللقطة

ينشئ `GET /reports/ledger-trial-balance` لقطة `ReportRun` داخل نطاق الشركة المخول فقط وبقدرة `reports.read`. مصدر الأرقام هو `FinanceJournalEntry` و`FinanceJournalLine` مباشرة، بالمحدد التالي:

```text
isSealed = true
AND status IN (POSTED, REVERSED)
AND ledgerRevision <= ReportRun.ledgerRevision
```

لا يستخدم التقرير `FinanceAccountDailyBalance` أو `FinanceAccountMonthlyBalance`، لأن إسقاطاتهما الحالية ليست مربوطة بإصدار دفتر لقطة التقرير؛ قيد متأخر بتاريخ قديم قد يغير الإسقاط دون أن يكون جزءاً من التقرير المجمد.

يبقى أصل العملية الملغاة ضمن تاريخ عمله، ويظهر قيد الإلغاء كتأثير مستقل في تاريخ عمل الإلغاء. لا تستخدم قراءة الحالة الحالية وحدها لإعادة كتابة تقرير تاريخي.

## الفترة والصيغة

الفترة متصلة وشاملة `[S,E]`. لا يقبل ميزان المراجعة اختيار أشهر متباعدة: ذلك يكسر المعادلة بين الافتتاح والحركة والختام. منتقي الفترة المركزي يبقي دعم الأشهر المتعددة للتقارير المناسبة، لكن هذا التقرير يمرر `allowNonContiguousMonths=false`؛ يستخدم المستخدم شهراً واحداً أو ربعاً أو سنة أو نطاقاً متصلاً.

```text
D0/C0 = مجموع المدين/الدائن قبل S
PD/PC = مجموع المدين/الدائن من S إلى E

openingDr = max(D0-C0, 0)       openingCr = max(C0-D0, 0)
closingDr = max(D0+PD-C0-PC, 0) closingCr = max(C0+PC-D0-PD, 0)
```

يحسب الخادم بدقة أربع منازل عشرية، ويتحقق أن إجمالي المدين يساوي إجمالي الدائن للافتتاح والحركة والختام، ثم يرسل عرض منزلتين عشريتين. لا يجمع المتصفح القيم المعروضة.

## نطاق الحسابات والدليل

يشمل التقرير الحسابات النشطة، وأي حساب مؤرشف له أثر دفتري ضمن اللقطة حتى `E`، والحسابات النظامية حتى إن كانت صفرية. خيار إظهار الصفر يغير الصفوف المعروضة فقط ولا يغير الإجماليات.

كل قيمة غير صفرية تفتح دليلاً مقسماً خادمياً داخل `reportRunId` نفسه. نطاق الدليل يصرح به: افتتاحي قبل `S`، حركة داخل `[S,E]`، وختامي حتى `E`. يمكن فتح القيد المصدر للعرض فقط؛ لا توجد أزرار تعديل أو إلغاء أو تصدير داخل التقرير.

## ما ليس في R1

- لا مقارنة فترات أو fold-all أو تسلسل شجرة حسابات؛ دليل الحساب الحالي مسطح ومعتمد على ترتيب نوع الحساب/الكود.
- لا P&L رسمي أو ميزانية عمومية أو تدفق نقدي أو امتثال ضريبي.
- لا تصدير، حتى تتوفر مهمة مخرجات مقيدة بـ`ReportRun` المجمد.
- لا دعم FX أو تجميع شركات؛ العملة الوظيفية لشركة مخولة واحدة فقط.

## التحقق

`npm run verify:ledger-trial-balance-policy` يتحقق من صيغ الافتتاح/الحركة/الختام، تعادل إجماليات المدين والدائن، ودلالة الأصل مع الإلغاء. اختبار التكامل التشغيلي يظل مطلوباً بعد اكتمال تغييرات العمليات المتوازية التي تمنع بناء API الشامل حالياً.
