# ملحق قرار أولوية المالك — بصيرة ثم المالية التشغيلية

التاريخ: 2026-08-16
الحالة: معتمد

هذا الملحق يضبط ترتيب التنفيذ بعد المبيعات اليومية، ولا يغيّر حدود الموديولات أو قواعد مصدر الحقيقة. ويحل محل أي ترتيب لاحق متعارض في خارطة البناء المؤرخة 2026-08-15.

## الترتيب المعتمد

1. **بوابة بصيرة B التقنية:** سجل المهارات والحدود والإيصالات والصلاحيات، بلا محادثة أو مزود حي. مكتملة في `AI_GATE_B_RUNTIME_DELIVERY_2026-08-16.md`.
2. **المشتريات والمصروفات:** مستند مالي موحّد، المورد، الضريبة، التخصيص، الدليل، التصحيح والعكس عبر Journal فقط.
3. **الخزائن والتدفقات المالية التشغيلية:** التحويلات، تسليم النقد والجرد الإداري، وواجهات الذمم والدفعات؛ من دون كشف بنكي شامل.
4. **التقارير وread models:** فلاتر مركزية، دفتر الأستاذ وميزان المراجعة والذمم وأرصدة الخزائن وإسقاطات المال، جميعها server-side ومتوافقة مع Journal.
5. **بصيرة المفيدة للمستخدم:** موصل مزود واحد بعد قرار احتفاظ مستقل، ثم أدوات قراءة ضيقة فوق التقارير المعتمدة وevaluation عربي. واجهة المحادثة بعد ذلك فقط.
6. **بقية الموديولات التشغيلية بحسب الأولوية المعتمدة لاحقاً.**
7. **التسويق وGoogle ثم البريد والأدلة الواردة/OCR:** في آخر المسار الحالي، كل نطاق بوابة منفصلة. لا OAuth أو مزامنة أو رد Google أو Gmail أو Telegram أو OCR قبل مصدر البيانات والعقود والـworker المحكوم.

## قواعد لا تتغير

- السجل المحاسبي وread models المتصالحة معه هما المصدر الوحيد للأرقام المالية والتقارير وإجابات بصيرة المالية.
- تبقى بصيرة بلا SQL حر، بلا تصفح أو ملفات حرة، وبلا فعل مالي أو خارجي إلا عبر قرار مستقل ومراجعة بشرية؛ واستثناء الردود الآلية على Google يبقى مقيداً بسياسة النجوم المعتمدة ولا يبدأ قبل بوابة Google الخاصة به.
- لا يبنى موديولا أعمال نشطان بالتوازي. كل نطاق يغلق بعقود وخلفية واختبارات وواجهة أصلية وقبول مالك قبل التالي.
