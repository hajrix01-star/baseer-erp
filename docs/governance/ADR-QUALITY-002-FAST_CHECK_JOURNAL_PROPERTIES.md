# ADR-QUALITY-002 — اختبارات خصائص القيد المالي عبر fast-check

**الحالة:** تحقق محلي مكتمل.

يعتمد API `fast-check@4.9.0` (MIT) كتبعـية تطوير فقط. لا تنفذ المكتبة أي
اتصال شبكي أو قاعدة بيانات؛ تولّد مدخلات اختبار محلية قابلة لإعادة التشغيل.

نُقل تطبيع أسطر القيد إلى دالة نقية مركزية قبل أي وصول إلى قاعدة البيانات.
يتحقق الأمر `npm run verify:journal-properties` من خاصيتين عبر مدخلات
عشوائية مضبوطة:

1. مجموع المدين يساوي مجموع الدائن دائماً لقيد صحيح بمبالغ decimal من أربع
   خانات.
2. أي فرق مقداره `0.0001` يُرفض قبل أن يلمس القيد قاعدة البيانات.

تبقى المعاملات، seal، RLS، والحفظ الذري في الخدمات الخادمية القائمة؛ هذه
اختبارات إضافية وليست بديلاً عن `verify:finance-gate-b-db` أو عن مراجعة
السياسة المالية.
