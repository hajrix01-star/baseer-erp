# بصيرة — بوابة التشغيل B وسجل التسليم

التاريخ: 2026-08-16
الحالة: مكتملة ومتحقق منها محلياً وعلى قاعدة Docker التجريبية فقط. لا يوجد مزود حي ولا محادثة مستخدم.

## ما تم بناؤه

- سجل مهارات مركزي مملوك للكود، بحالات `PLANNED` و`VALIDATED` و`PILOT` و`ACTIVE` و`SUSPENDED` ومستويات أثر S1 إلى S4. لكل مهارة إصدار وإصدار سياسة وصلاحيات مطلوبة محددة.
- بوابة تشغيل خادمية لا تقبل إلا `moduleKey` و`skillKey` ومفتاح عدم التكرار. تستنتج المستأجر والشركة والمستخدم والصلاحيات من الجلسة الحية، ولا تثق بسياق المتصفح.
- حد طلبات لكل مستأجر/شركة/مستخدم: 30 طلباً جديداً خلال خمس دقائق. الإعادة بنفس المفتاح لا تنشئ إيصالاً إضافياً.
- إيصال تنفيذ مدقق يسجل المهارة وإصدارها وإصدار السياسة، وإصدار هوية بصيرة المركزية أو هوية الشركة إن وجدا، من دون prompt أو إجابة أو سر أو بيانات أعمال خامة.
- قيد قاعدة بيانات يمنع بيانات مهارة جزئية: إما إيصال قديم بلا حقول مهارة، أو مفتاح مهارة غير فارغ مع إصداري المهارة والسياسة معاً وبقيم موجبة. وتظل أسطر RLS/FORCE RLS مفعلة.
- إعداد مزود الذكاء وهوية بصيرة المركزية محصور بمالك المستأجر المركزي؛ هوية الشركة تظل مقيدة بصلاحيات الشركة.
- سجل مزودات offline فقط. لا فك للسر ولا اتصال شبكة ولا أداة قراءة أو RAG أو ملف أو SQL حر أو تنفيذ مالي أو نشر Google في هذه المرحلة.

## أدلة التحقق

- `npx prisma validate` و`npx prisma generate` نجحا، وCI يعيد التوليد ثم يفشل إذا لم تكن المخرجات المولدة ملتزمة في Git.
- فحص TypeScript وبناء contracts وAPI نجحا.
- `npm run check:permissions` و`npm run check:ai-gate-b` نجحا؛ الأخير يمنع اتصال مزود أو فك تشفير في Gate B.
- طبقت الترحيلتان `20260816200000_ai_gate_b_runtime_receipts` و`20260816201000_ai_gate_b_receipt_integrity` على `baseer_erp_test` فقط.
- `npm run verify:ai-gate-b-db` يتحقق ذاتياً من الأعمدة وRLS والترحيلات والقيد والفهرس، ويختبر رفض إدخال سجل مهارة ناقص داخل معاملة متراجعة.
- `npm run verify:ai-gate-b-http` يثبت المصادقة وRBAC وعزل الشركات وإعادة الطلب ومفتاح مختلف بمحتوى مختلف وحد الطلبات والإيصال مع حدث التدقيق الذري وحد المزود offline.

## ما لا يزال ممنوعاً

لا Chat UI، ولا API key أو مزود حي، ولا conversation أو memory أو tools أو RAG أو OCR أو نشر مراجعات Google أو قيد أو صرف أو تعديل بيانات من بصيرة.

## الخطوة التالية

المسار النشط التالي هو مستندات المشتريات والمصروفات والالتزامات، ثم read models مالية متصالحة مع Journal. بعد مصدر قراءة رسمي ومقاييس جاهزة، يمكن تفعيل مهارة واحدة في كل مرة عبر evaluations عربية وقرار مالك منفصل.
