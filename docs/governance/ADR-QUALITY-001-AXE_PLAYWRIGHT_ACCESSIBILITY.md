# ADR-QUALITY-001 — فحص الإتاحة الآلي عبر axe وPlaywright

**الحالة:** تحقق محلي مكتمل.

يعتمد الويب `@axe-core/playwright@4.13.0` (MPL-2.0) كتبعـية تطوير فقط.
تشغّل أداة axe داخل متصفح Playwright الحقيقي، ولا ترسل أي صفحة أو بيانات إلى
خدمة خارجية.

أضيف اختبار WCAG 2 A/AA لصفحة الدخول بالعربية والإنجليزية، وعلى مشروعي
سطح المكتب والجوال. نتيجة الفحص يجب ألا تحتوي انتهاكات؛ لا توجد قائمة
استثناءات أو إخفاء لمشاكل الإتاحة.

هذا حارس جودة وليس بديلاً عن اختبار لوحة المفاتيح، RTL/LTR، قارئ الشاشة أو
المراجعة المرئية. أي primitive أو مسار حساس جديد يضيف فحص axe خاصاً به في
ملف Playwright المناسب عند دخوله نطاق العمل.
