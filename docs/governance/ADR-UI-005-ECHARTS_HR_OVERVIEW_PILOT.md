# ADR-UI-005 — ECharts للوحة HR التشغيلية

**الحالة:** مقبول للتحقق المحلي ودمج المصدر فقط، وليس تقريراً مالياً أو إنتاجياً.

## القرار

يعرض `BaseerChart` مؤشرات القوى العاملة من `GET /hr/overview` الخادمي فقط:
الموظفون النشطون، الموظفون في إجازة، والخدمات التي تحتاج متابعة. وهو لا يحسب
أي قيمة في المتصفح، ويعرض بجانب الرسم ملخصاً نصياً وجدول HTML مطابقاً.

المكوّن lazy، يستورد ECharts modular SVG مع Bar/Grid/Tooltip/ARIA فقط، يفعّل
ARIA، يستجيب لتغيير الحجم، ويتخلص من الرسم عند الإغلاق.

## حد الأداء

الحجم الفعلي للتفاعل `492,648 B` (gzip `166.24 kB`)؛ لذلك له سقف صريح
`500,000 B` مستقل. لا يدخل حزمة البدء أو أكبر رحلة عادية. يمنع تجاوز السقف
ترقية المكتبة أو إضافة نوع رسم جديد دون ADR جديد.

## الحدود

لا توجد بيانات مالية أو API/RLS/permission changes. الرسم ليس وسيلة الوصول
الوحيدة للمعلومة، ولا يتخذ قراراً أو يغير بيانات.
