# ADR-UI-004 — TanStack Query لملخص HR

**الحالة:** مقبول للتحقق المحلي ودمج المصدر فقط ضمن بوابات المكتبات الحالية

**التاريخ:** 2026-08-22

## القرار

يعتمد `@tanstack/react-query@5.101.4` خلف `BaseerCompanyReadQuery` في ملخص
الموارد البشرية للقراءة فقط. مفتاح القراءة يتضمن المورد ومعرف الشركة ورمز
الجلسة. عند تغيير الشركة أو الجلسة يعاد تركيب cache مستقل، فلا تظهر نتيجة
سابقة للمستخدم الجديد.

## الحدود

- لا mutation ولا حساب مالي أو قرار صلاحية في المتصفح.
- مصدر الرقم هو endpoint الخادمي الحالي `/hr/overview`؛ المكتبة تدير التحميل
  والخطأ وإعادة المحاولة فقط.
- لا cache عالمي مشترك: `gcTime: 0` و`retry: false`، وتلغى العملية عند إلغاء
  الطلب عبر `AbortSignal`.
- لا تغيير API أو RLS أو CompanyContext.

## الدليل

TypeScript وbuild وميزانية الويب تمر؛ بقيت حزمة البدء `243,938/250,000 B`
وأكبر رحلة `84,443/85,000 B`. اختبار HR quick actions يمر على سطح المكتب
والجوال فوق قراءة الملخص الجديدة.

## إعادة التقييم

أي استعمال للقائمة أو mutation أو cache متعدد الشاشات يحتاج ADR واختبارات
company-switch وinvalidation خاصة به.
