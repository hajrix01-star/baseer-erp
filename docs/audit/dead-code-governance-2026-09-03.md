# حارس الكود غير المستخدم — baseline الأول

**التاريخ:** 2026-09-03
**الحالة:** مطبق في التحقق المستمر؛ لا حذف تلقائي.

## ما الذي يحميه الحارس

`npm run check:dead-code` يشغّل Knip على المصدر القابل للتنفيذ في ثلاث مساحات فقط:

- `apps/web`
- `apps/api`
- `packages/contracts`

ويفشل عندما يظهر **ملف مصدر جديد غير مستخدم** لم يُراجع بعد. لا يفشل عندما يختفي مرشح قديم؛ يعرضه كمرشح تم حله لكي يُزال من baseline بعد مراجعة التغيير.

المخرجات الكاملة الاستشارية متاحة عبر `npm run audit:dead-code`. وهي تعرض الملفات والتبعيات غير المستخدمة والاعتمادات غير المعلنة، لكنها ليست أمراً بالحذف.

## الحدود المتعمدة

- لا تدخل Prisma المولدة أو `dist` أو migrations في حكم «ميت»؛ هذه مخرجات أو تاريخ بيانات.
- لا تدخل سكربتات التشغيل اليدوي والترحيل في baseline الحالي. كثير منها يُستدعى من إجراءات استعادة أو عمليات موجّهة، ولا يكفي graph الاستيراد لإثبات موته. تسجل للمراجعة التشغيلية/المالك قبل أي إزالة.
- لا يقرأ الحارس قاعدة البيانات ولا يحتاج `DATABASE_URL`؛ عُطّل تكامل Prisma داخل التحليل لأن مصدره يحتاج بيئة قاعدة بيانات وهو خارج نطاق ملفات المصدر غير المستخدمة.

التحقق النصي في المصدر لم يجد استيراداً لهذه الملفات. مع ذلك تبقى مرشحات: قبل الحذف يجب فحص التحميل بالاسم، ملفات النشر، والمالك الوظيفي لكل ملف.

## نتائج الاعتمادات: ليست أوامر حذف

- `@internationalized/date` و`react-aria-components` في الويب يظهران مرشحين؛ وهما مرتبطان بملفّي عناصر التاريخ/النص غير المستخدمين. يراجعان مع هذين الملفين كحزمة واحدة.
- `@prisma/client` و`pg` و`@types/pg` في API تظهر كمخرجات ثابتة لأن الاستعمال الفعلي في توليد Prisma وإعدادات التشغيل مستثنى من هذا النطاق. لا تزال ضرورية لمسار النشر/القاعدة، لذلك **لا تُحذف**.
- `@interactjs/types` يُستورد مباشرة في `hr-attendance-roster-editor.tsx` لكنه يصل حالياً تبعياً عبر `interactjs`. هذه ملاحظة صحة manifest: يضاف كاعتماد مباشر فقط بعد قرار مالك الواجهة، ولا علاقة لها بحذف الكود.

## طريقة العمل عند كل نتيجة

1. إثبات الاستعمال الثابت والديناميكي والتشغيلي.
2. تصنيف العنصر: إزالة، إضافة كنقطة دخول موثقة، أو عنصر تشغيلي مقصود.
3. تنفيذ تغيير صغير قابل للمراجعة مع اختبار القسم المتأثر.
4. تحديث `scripts/dead-code-files-baseline.json` في نفس التغيير، لا في تغيير منفصل لإخفاء المشكلة.
