- **مرشح الفحص:** تغييرات علاجية فوق `cb93129` قبل تثبيت مرشح Git التالي
- **القرار:** **CONDITIONAL GO لمرشح المصدر**
- **النطاق:** طلبات الشراء والاستلام والعهدة، المخزون وWAC، الوصفات والاستهلاك الداخلي، الأصول والضمانات، والمبيعات اليومية. لا يشمل الترحيل الخارجي أو النشر الحي.

## الأدلة الناجحة

- `npm run verify:operations-purchase-cycle` — مرّ: قنوات النقد/العهدة/التحويل، مخزون وWAC، وصفات، استهلاك داخلي، تقارير، cursor ونطاق الشركة وتصحيح المالك.
- `npm run verify:operations-assets-warranty` — مرّ: طابور المتابعة، الأصل والضمان، idempotency، ومنع الترحيل المالي غير المقصود.
- `node apps/api/dist/operations/operations-read-performance.policy-verification.js` — مرّ: نطاق القراءة وتعاقد first-paint.
- `npm run verify:daily-sales-http` — مرّ: عقد المبيعات اليومية عبر API معزول.
- اختبار HTTP `scripts/run-operations-workspace-authorization-verification.mjs` — مرّ: catalog-only لا يصل إلى receipt الكامل أو الملخص، والمجموعة الكاملة فقط تنجح.

| المعرّف | الحالة | العلاج والدليل |

## ملاحظات غير مانعة

- `OPS-P2-002`: مساحة الأصول والضمان ما زالت تقرأ حتى 1,000 مستند مصدر و10,000 أصل مع الأسطر بلا pagination. لا فشل وظيفي مثبت في الحجم الحالي، لكنه يحتاج receipt محدوداً أو cursor قبل نمو البيانات إلى هذا الحد.
- الواجهة في هذا القسم تستخدم عميل API المركزي، ولم يظهر ارتباط بـAPI قديم. بقيت رحلة workspace الكاملة مقصودة للمدير ذي صلاحيات القراءة الكاملة فقط.
- بوابات إطلاق الإنتاج الخارجية (CI/digests، DNS/HTTPS، النسخ والاستعادة) ما زالت منفصلة وغير منجزة ضمن هذا القسم.

## التوقيع

**فريق تسليم ألفا: توقيع قبول مشروط للقسم في مرشح المصدر.** لا يوجد مانع P0/P1 مفتوح في العمليات والمخزون والمستندات التجارية بعد إعادة التحقق. تبقى ملاحظة pagination للأصول والضمان مسجلة قبل التوسع الكبير.
