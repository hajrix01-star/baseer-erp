# تسليم ألفا — قسم المالية والمحاسبة

- **تاريخ الفحص:** 2026-09-03
- **مرشح الفحص:** `63511a6` مع إصلاح العمل غير الملتزم لـ`FIN-ACC-001`
- **القرار:** **CONDITIONAL GO لمرشح المصدر**
- **النطاق:** دليل الحسابات، القيود والحركات، الفترات، الموردون/الدفعات، RLS والعقود المالية. لا يشمل الإطلاق الخارجي أو سياسات الضرائب المحلية غير الموثقة.

## النتائج المثبتة

- `npm run verify:finance-gate-b-db` مرّ: توازن وختم وعدم تعديل القيد، العزل، الاستحقاقات والدفعات، الإلغاء، التكرار والتحويلات المتزامنة.
- `npm run verify:finance-period-race` مرّ: الإقفال ينتظر الترحيل النشط ثم يرفض الترحيل الجديد في الفترة المغلقة.
- `npm run verify:finance-accounts-http` مرّ: RBAC، عزل الشركة، receipt حقيقي، والحد المستقبلي.
- `npm run check:finance-rls` مرّ: 36 نموذج Prisma مع ENABLE+FORCE وسياسة المستأجر.
- `npm run check:web-financial-boundaries` و`npm run verify:journal-properties` و`npm run verify:finance-period-payroll-close-policy` مرت.

## المانع المغلق

| المعرّف | الحالة | العلاج والدليل |
| --- | --- | --- |
| `FIN-ACC-001` | مغلق | كان `businessMonths` لا يتقاطع مع `asOf`، فيتيح إسقاطاً أو حركة مستقبلية من شهر مختار. صارت الأرصدة اليومية وحركات اليومية تستخدم predicate خادمياً يتقاطع دائماً مع `businessDate <= asOf`. أضاف اختبار HTTP قيداً مستقبلياً مختوماً بتاريخ 2026-08-21 ويثبت استبعاده من الإجمالي والحركة عند `businessMonths=2026-08`. |

## ملاحظات غير مانعة

- `FIN-P2-001`: استعلام دليل الحسابات محدود بـ500 حساب بلا cursor؛ مناسب للنطاق الصغير الحالي لكنه يحتاج ترقيم صفحات أو حد تشغيلي موثق قبل توسع شجرة الحسابات.
- `FIN-P3-001`: تحذير توافق من `pg@8.23` عبر `@prisma/adapter-pg` عن نمط سيُزال في pg 9؛ لا عطل مالي مثبت الآن، ويلزم تتبعه قبل ترقية كبرى.
- لا يزال إطلاق الإنتاج مقيداً ببوابات مستقلة: CI على commit منشور، manifest/digests الفعلية، وGate C الخارجي للنسخ والاستعادة وDNS/HTTPS.

## التوقيع

**فريق تسليم ألفا: توقيع قبول مشروط للقسم في مرشح المصدر.** لم يبق مانع P0/P1 داخل المالية بعد إعادة التحقق؛ يمكن بدء فحص القسم التالي مع بقاء الملاحظات والبوابات الخارجية في سجلها.
