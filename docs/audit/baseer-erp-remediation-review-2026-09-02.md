# إعادة فحص إصلاحات BASEER ERP — 2026-09-02

**المرشح:** شجرة عمل فرع `codex/attendance-release-candidate` فوق commit
`62994c`، وليست artifact أو نشر إنتاجي.

**النطاق:** إصلاح امتيازات دور قاعدة private-online، إزالة تجاوزات URL الواجهة
وإعادة الجلب غير المقصود، وتحسين إلغاء طلبات الحضور، ثم إعادة فحص الجودة والسعة.

## الأدلة المنفذة

| المسار | الدليل | النتيجة |
|---|---|---|

| واجهة/API | `npm run check:web-api-transport` | نجح؛ مصدر عنوان API المركزي فقط. |
| الواجهة | `npm run check --workspace @baseer-erp/web` وbuild production | نجحا. |
| عزل ERP | فحوص الصلاحيات والجلسة وRLS للمجالات الستة | نجحت. |
| حضور | `npm run verify:attendance-http` | نجح في البيئة المعزولة. |
| جداول الحضور | `GET /v1/attendance/schedule-workspace` ضمن `verify:attendance-http` | نجح؛ يجمع 4 قراءات أولية للواجهة في طلب HTTP واحد، مع page limit القائم. |
| أداء الواجهة | build production ثم `npm run verify:web-budget` | نجح بقياس gzip: startup 79.5KB، أكبر رحلة 56.6KB، ورسم ECharts lazy 179.6KB؛ تحليل المبيعات لا يحمّل ECharts. |

| Gate C محلي | `Invoke-GateC-LocalRehearsal.ps1` | نجح؛ استعادة معزولة بلا شبكة تطابق 201 جدولاً و15,622 AuditEvent، والدور المحدود صادق دخوله. |
| قبول محلي | `npm run verify:acceptance:quick` | نجح كاملاً: 148 migration سليمة، 137 صلاحية، وحراس RLS والنوعية والتعريب والجلسة. |

## قرار فريق تسليم ألفا

**NO-GO للإطلاق الإنتاجي الآن؛ مرشح تقني ثابت يحتاج CI وتشغيلاً.** أُغلقت
عيوب الشريحة وحراسها: صلاحيات قاعدة البيانات، ترتيب الإقلاع، receipt الحضور،
النقل، الجرد، وميزانية الواجهة أدلتها خضراء. ثُبّتت الإصلاحات في commit؛ لكن
لا يوجد artifact/CI مستقل ولا Gate C تشغيلي للبيئة الحقيقية، وهما مانعا إطلاق P1
لا يجوز تجاوزهما بلا تفويض. لا توجد أي عملية نشر أو تعديل بيانات حية ضمن هذا الفحص.
