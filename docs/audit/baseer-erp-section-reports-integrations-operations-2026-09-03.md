# تسليم ألفا — قسم التقارير والتكاملات والتشغيل

- **تاريخ الفحص:** 2026-09-03
- **مرشح الفحص:** `e6b145b`
- **قرار القسم:** **CONDITIONAL GO لقراءة/تجربة التقارير من مرشح المصدر**
- **قرار الإطلاق الإنتاجي:** **NO-GO**
- **النطاق:** تقارير وأدلة وdocument runs، عزل التقارير، النقل API/الويب، النسخ/الاستعادة، provenance، ومتطلبات النشر الخاصة.

## أدلة ناجحة

- `npm run verify:reports-http` — مرّ: 401/403، الصلاحيات، عزل الشركة/المستأجر، document actor scope، المعاينة/التصدير، الأدلة والمصادر، انتهاء report run والتجميد/checksum.
- `npm run check:reports-rls` — مرّ: 23 نموذج تقارير محمية بـENABLE+FORCE وسياسة المستأجر.
- `npm run check:web-api-transport` — مرّ: الواجهة تستخدم النقل المركزي ولا يبقى مسار `/v1` متشعباً.
- `npm run check:backup-gate-1` و`npm run check:backup-worker` — مرا: ضوابط أساس النسخ، lease والـopt-in للعامل.
- `node scripts/check-release-provenance-contract.mjs` — مرّ: العقد المحلي للـdigest وmanifest وattestations.

## ملاحظات غير مانعة

- `REP-OPS-P2-001`: سياسة الاحتفاظ لا تحذف artifacts ولا تعيد المحاولة أو ترسل تنبيهاً خارجياً؛ لا تُعامل كأتمتة احتفاظ مكتملة حتى يضاف ذلك أو يعتمد إجراء تشغيلي بمالك ووتيرة.
- `REP-OPS-P2-002`: `daily-sales-client.ts` يحتفظ بمسار توافق guarded لـ`isOwner?`. ليس اتصالاً موازياً قديماً، لكنه دين تقادم يزال عند اعتماد minimum backend version.

## التوقيع

**فريق تسليم ألفا لا يوقّع إطلاق الإنتاج.** التقارير والعزل والنقل المركزي لها دليل محلي كافٍ للتجربة من مرشح المصدر؛ إنما الاستعادة والتشغيل الخارجي مانعان P1، ولذلك يبقى القرار النهائي NO-GO حتى إغلاقهما.
