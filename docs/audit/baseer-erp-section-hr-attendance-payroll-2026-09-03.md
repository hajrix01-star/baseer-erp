## الأدلة الناجحة

- `npm run verify:hr-http` — مرّ: الصلاحيات، العزل، cursors، الأوامر idempotent ومسارات العكس.
- `npm run verify:hr-lifecycle` — مرّ: onboarding والراتب والسلف والخدمات والـpayroll والمخالصة وعكسها والتزامن والتواريخ.
- `npm run verify:attendance-http` — مرّ: قواعد العمل أعلاه، receipt المحدود، الموقع والاحتفاظ، ومدخل 12 عملية متزامنة.
- `npm run check:hr-rls` — مرّ: 29 نموذج HR محمي بـENABLE+FORCE وسياسة المستأجر.
- `npm run verify:hr-financial-integrity` — مرّ: قفل HR المالي، التسلسل الزمني، تاريخ المدفوعات ورصيد الحساب اليومي.

## ملاحظات غير مانعة

- `HR-P2-001`: حقل `retentionUntil` لمستندات الموظفين موجود، لكن لا يوجد حتى الآن دليل مجدول لحذف/حجب تنزيل المستند بعد انتهائها. لا يُدّعى حذف تلقائي؛ يلزم تحديد سياسة احتفاظ ثم تنفيذها والتحقق منها قبل أي التزام خصوصية بهذا المعنى.
- الإطلاق الإنتاجي ما زال مشروطاً بسلسلة المرشح الخارجية وGate C (CI المنشور، manifest/digests الفعلية، DNS/HTTPS، والنسخ/الاستعادة)، المسجلة في أقسام المنصة.

## التوقيع

**فريق تسليم ألفا: توقيع قبول مشروط للقسم في مرشح المصدر.** لا يوجد مانع P0/P1 مفتوح داخل HR أو الحضور أو الرواتب بعد إعادة التحقق. تبقى ملاحظة مستندات الموظف وبوابات التشغيل الخارجية مسجلة ولا تُخفى.
