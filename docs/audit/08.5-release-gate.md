# بوابة جاهزية الإطلاق

## القرار

# NO-GO

القرار مبني على فشل شروط حجب مستقلة، وليس على غياب دليل واحد فقط: تخزين الملفات الإنتاجي غير مكتمل، ولا توجد شهادة نسخ احتياطي/استعادة حديثة تشمل البيانات والملفات، ولا يوجد مسار مراقبة وتنبيه إنتاجي، ومرشح CI يفشل التعريب والميزانية وتوجد فيه صفحتان مرئيتان غير منفذتين كما ينبغي.

## الحد الأدنى للانتقال من NO-GO

لا يُعاد تقييم القرار قبل نجاح G01 وG02 وG04–G07 وG09–G17 وG19، وحسم G20 حسب نمط الإطلاق. النجاح يعني دليلًا مربوطًا بمرشح Git واحد، وبيئة staging مماثلة للإنتاج، ونتائج محفوظة لا تعتمد على مخرجات build أو rehearsal قديمة.
