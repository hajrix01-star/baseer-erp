## تحقق ما بعد الإقفال

- حالة كل شركة: نشطة وقفل مراجعة الترحيل مرفوع.
- جميع الأقسام المصدرية إما مكتوبة ومطابقة، أو غير منطبقة، أو محفوظة كدليل تاريخي بمعالجة معتمدة.
- لا توجد موجات `RUNNING` أو `FAILED` أو `otherOpen` في أي حزمة.
- لا تتضمن عملية الإقفال إعادة كتابة الفواتير أو القيود أو الأرصدة؛ إنها تثبت فقط أن الأدلة والخرائط والمطابقة اجتازت بوابة الإقفال.

## معالجة البيانات الرئيسية المكملة

- أُنجزت معالجة موردي **دوحة المستهلك** قبل الإقفال: تحديث الموردين المربوطين، استيراد الموردين التاريخيين غير المربوطين بلا تكرار، نقل الأرقام الضريبية الصحيحة عند توفرها، وتعيين الفئات الافتراضية من مصدر موثوق فقط.
- حُسمت الاستثناءات المعتمدة للفئات الافتراضية: تحويل الورق ← بلاستيكات، الشركة السعودية للكهرباء ← مصروفات/كهرباء، والجهة التاريخية غير المسماة ← مصروفات/إقامات وجوازات.
- لا تغير هذه المعالجة أي فاتورة تاريخية أو قيد أو رصيد أو مبلغ؛ نطاقها بيانات المورد والفئة الافتراضية فقط.
