# معالجة روابط ملفات الموظفين القديمة — 2026-08-30

## الأثر

قد تظهر قائمة موظفي الشركة بصورة صحيحة مع رسالة «السجل المطلوب غير موجود». لا يعني ذلك فقد الموظفين أو نقص صلاحية المستخدم.

## السبب الجذري

يحمل رابط ملف الموظف المرحلة `stage=employee-<id>`. كان تبديل الشركة أو إعادة استيراد الموظفين يعيد تحميل الصفحة مع الإبقاء على هذه المرحلة، بينما معرف الموظف خاص بالشركة السابقة أو بالسجل الذي استُبدل. تحمي واجهة API العزل الصحيح بـ `tenantId` و`companyId`، فترد بـ 404 للسجل القديم في حين تنجح قائمة الشركة الحالية.

## المعالجة والوقاية

- عند تبديل الشركة، تحذف الواجهة أي `stage` قبل إعادة التحميل.
- إذا عاد طلب ملف موظف بـ 404، تُستبدل المرحلة برابط قائمة الموظفين بدون إضافة إدخال جديد إلى سجل المتصفح، وتعرض ملاحظة مفهومة للمستخدم.
- لا تُخفف قيود العزل في API ولا تُنشأ بيانات بديلة.
- يغطي اختبار E2E رابط ملف قديم ويتحقق من عودته للقائمة وعدم دخول الطلب في حلقة إعادة محاولة أو إظهار رسالة 404 العامة.

## التحقق

شغّل فحص الواجهة واختبار HR المقلد بعد أي تغيير في التوجيه أو تبديل الشركة.
