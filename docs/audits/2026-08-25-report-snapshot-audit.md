# تدقيق لقطات التقارير قصيرة العمر — 25 أغسطس 2026

## نطاق اللجنة

أجرت لجنة من ثلاثة مسارات مستقلة مراجعة قراءة فقط: الخادم، الواجهة، والاختبارات. المقصود بـ«لقطة تقرير» هنا هو `ReportRun` قصير العمر، وليس كل كيان يحتوي حقل `expiresAt` أو كل cache في المتصفح.

## الحصر الكامل

يوجد مسار `ReportRun` واحد مشترك، بصلاحية افتراضية **24 ساعة**. يرفض الخادم اللقطة غير الجاهزة أو المنتهية عبر `findReady`، ويعيد HTTP 404. لا يوجد استعمال آخر لـ `ReportRun` أو `reportRunId` خارج التقارير الثلاثة التالية:

| التقرير | إنشاء اللقطة | تفاصيل مرتبطة باللقطة | الحالة |
| --- | --- | --- | --- |
| الأداء النقدي الشخصي | `GET /v1/reports/personal-cash-performance` | evidence/source، طباعة، Excel، حفظ | تفاصيل الأدلة والمصادر محمية؛ إجراءات المستندات بها فجوة |
| ميزان المراجعة | `GET /v1/reports/ledger-trial-balance` | evidence/source، طباعة، Excel، حفظ | تفاصيل الأدلة والمصادر محمية؛ إجراءات المستندات بها فجوة |
| التقرير الضريبي الداخلي | `GET /v1/reports/internal-vat` | evidence/source، طباعة، Excel، حفظ | تفاصيل الأدلة والمصادر محمية؛ إجراءات المستندات بها فجوة |

مركز القيادة لا ينشئ نوعاً رابعاً؛ إنه يعرض لقطة الأداء النقدي نفسها.

## ما عولج

تغطي آلية `withFreshReportRun` جميع طلبات **evidence/source** في أربعة أسطح واجهة:

- مركز القيادة.
- تقرير الأداء النقدي.
- ميزان المراجعة.
- التقرير الضريبي الداخلي.

عند 404 للّقطة، يعيد التطبيق توليد التقرير مرة واحدة ثم يعيد طلب الدليل أو المصدر باستخدام المعرّف الجديد. اختبار Playwright يحاكي انتهاء لقطة الأداء النقدي ويثبت فتح دليل اللقطة المجددة.

## إغلاق فجوة المستندات

كان المكوّن المشترك [report-document-actions.tsx](../../apps/web/src/report-document-actions.tsx) يرسل `reportRunId` مباشرة عند:

- طباعة التقرير.
- تصدير Excel.
- حفظ التقرير في مستندات التقارير.

تمت معالجتها: عند انتهاء اللقطة، يجدد المكوّن التقرير مرة واحدة ثم يعيد طباعة التقرير أو تصديره أو حفظه باستخدام المعرّف الجديد. يغطي ذلك التقارير الثلاثة.

بعد حفظ مستند التقرير بنجاح، يصبح عرضه مبنياً على `documentId` ولقطة محفوظة؛ لذلك لا يعتمد على `ReportRun` الحي ولا يتأثر بانتهائه.

## ضمانات إضافية منفذة

- يعيد الخادم الآن `REPORT_RUN_EXPIRED` بدلاً من 404 عام عند انتهاء اللقطة، فلا يعيد العميل توليد التقرير عند أي 404 غير متعلق بالانتهاء.
- يغطي فحص HTTP لقطة منتهية ويتحقق من الرمز الجديد.
- يغطي Playwright تجديد لقطة منتهية عند فتح الدليل وعند حفظ مستند التقرير.

## تغطية مستقبلية مقترحة

1. إضافة اختبارات انتهاء اللقطة لـ source، وميزان المراجعة، والضريبة، ومركز القيادة، وإجراءات الطباعة وExcel تحديداً.
2. يمكن مستقبلاً تضمين `expiresAt` في metadata العقود لعرض وقت انتهاء اللقطة أو تجديدها وقائياً؛ العقود الحالية لا تعرضه.

## الحكم

لن تتكرر فئة «لقطة التقرير المنتهية» في تفاصيل الأدلة أو المصادر أو الطباعة أو Excel أو الحفظ في الأسطح المعالجة. يعاد التجديد مرة واحدة فقط؛ أما الأعطال الأخرى مثل الصلاحيات أو انقطاع الشبكة فتظل أخطاء مستقلة برسائلها الصحيحة.
