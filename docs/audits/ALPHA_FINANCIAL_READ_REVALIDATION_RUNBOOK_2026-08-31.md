# سجل فريق ألفا — إعادة تحقق عقد العرض المالي

**الحالة:** مكتمل — اجتازت بوابة التحقق في 31 أغسطس 2026.
**سبب الإعادة:** وصلت تغييرات من مسار عمل موازٍ بعد إغلاق مراجعة 30 أغسطس؛ لا تعدّ نتائج الإغلاق السابق دليلاً على النسخة الحالية حتى تعاد مطابقة العقود والواجهات والاختبارات.

## السياسة الملزمة

1. كل واجهة إدارية أو تشغيلية أو تحليلية خارج التقارير تعرض المبالغ شاملة ضريبة القيمة المضافة فقط.
2. مصدر القيمة المعروضة، وحالتها، وأساسها هو الـ backend؛ لا يحسب المتصفح مالاً أو ينسق مبلغاً خاماً.
3. تقرير الربح والخسارة والتقارير القائمة لا تتغير دلالاتها أو حساباتها: يبقى افتراضها شامل الضريبة، ويبقى زر فصل الضريبة فيها فقط.
4. القيمة غير المكتملة هي `null`/`—` مع دليل جودة، وليست صفراً.

## التنفيذ الفعلي

- أُضيف الغلاف الاختياري المتوافق `financial-read.v1`: أساس الضريبة، المسموح، مصدر الحقيقة، الجودة، نطاق العملة وسياسة العرض. يبقى payload المتخصص في قسمه ولا تنكسر اللقطات أو العقود القديمة.
- تقرير الأداء النقدي/الربح والخسارة يحتفظ بـ`vatInclusive` وزر فصل الضريبة، وأصبح يعيد `display` و`sign` للمدين والدائن؛ بقيت القيم ذات أربع منازل لتوافق قراء API القديمة.
- قراءة تقويم التسويق ومركز القيادة تعلن `MIXED_ANALYTICS` و`VAT_INCLUDED` فقط وSAR واحداً، وتعيد نصوص العرض للمبيعات والصرف والهدف والمتوسط والرسم من الـbackend.
- مُدد الحارس ليشمل واجهة التقارير وملخصي التسويق ومركز القيادة؛ يمنع `formatMoney` وتحويل المبلغ الخام وإلحاق العملة محلياً في receipts ذات العرض الخادمي.
