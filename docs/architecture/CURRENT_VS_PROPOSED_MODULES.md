## قاعدة تفسير المقارنة

- **المقترح لا يعني نقل الكود أو الشاشة.** يعني إعادة بناء نفس الوظيفة المقصودة داخل موديول مسؤول عنها بشكل صحيح.
- **كل الأرقام والتواريخ والتقارير تأتي من الخلفية.** الواجهة تعرض ولا تحسب.
- **كل الموديولات تشترك في قاعدة مركزية واحدة** وهوية وشركة وصلاحيات وثيم وسجل تدقيق ونواة مالية واحدة.
- **لا يبدأ بناء أي صف** قبل دراسة سير عمله الحقيقي في نوركس وتسجيل قرار Preserve / Harden / Correct / Defer.
