## كيف يستخدمه مدير المشروع تلقائياً

1. يحدد الطلب والموديول أو المسارات المتوقعة.
2. يقرأ بطاقة الموديول في `modules.json` وملكية البيانات في `data-ownership.md` وسجل القرار في `adr-index.md`.
3. يصنف الأثر `LOCAL` أو `CONTROLLED` أو `ARCHITECTURAL` وفق `$alpha-architects-team`.
4. يعطي البناء المرجع؛ وبعد التغيير يحدث سجل `change-impact/` وحقول التحقق عند وجود أثر معماري.
5. يعطي التسليم معرف المرجع وسجل الأثر؛ لا يبدأ تسليم بخريطة قديمة أو مفقودة.

## قاعدة الحداثة

هذا الفهرس لا يحل محل الكود. إذا كان الطلب يمس مساراً أو عقداً غير مفهرس، أو تغيرت الملفات الأساسية بعد آخر تحقق بقرار معماري، يصنف `ARCHITECTURAL` حتى يحدث المرجع. لا تعاد قراءة كل المشروع لتغيير محلي مغطى ببطاقة موديول حديثة.
