# تنسيق ألفا الذكي — سياسة المهارات والأوامر والأجنتات

**المالك:** مدير المشروع
**المرجع:** `$alpha-efficient-orchestration`
**الهدف:** الدليل الكافي بأقل تكرار، لا أقل تحقق.

## تدفق العمل

```text
طلب متعدد الخطوات
  → بصمة مهمة (project + revision + intent + scope)
  → registry / سجل أثر / نتائج وأجنتات حية
  → دليل موجود؟ نعم: إعادة استخدامه
                 لا: مهارة أو أمر أو أجنت واحد بملكية محددة
  → تحقق متدرج من الضيق إلى الواسع
  → موجز دليل واحد للبناء أو التسليم
```

## مصفوفة اختيار القدرات

| الإشارة | القدرة المطلوبة | ما لا يُفعل تلقائياً |
|---|---|---|
| تغيير تطبيق | فريق ألفا المعماريين | مسح خريطة كاملة إذا كان registry حديثاً |
| تنفيذ ميزة/إصلاح | فريق ألفا للبناء | استدعاء تسليم قبل وجود مرشح ودليل |
| قبول أو إطلاق | فريق تسليم ألفا | إعادة بحث المعمارية من الصفر |
| ترحيل أو قطع بيانات | فريق ألفا للترحيل | استدعاءه لتعديل واجهة أو bug محلي |
| تغيير واجهة Baseer | مهارة Baseer UI عند أثر تجربة فعلي | مكتبات/مهارات بصرية غير لازمة |
| تغيير عقد/بيانات/صلاحية/مال | المعماريون ثم المختص المناسب | تفويض عام متوازٍ بلا نطاق |

## قواعد منع التكرار

1. لا أمر، بحث، اختبار، أو استكشاف ثانٍ مع بصمة مطابقة ونتيجة حديثة.
2. لا أجنتين يملكان السؤال أو الملفات نفسها؛ التفويض يذكر المالك والمخرج والدليل.
3. لا يُرسل إلى الأجنت إلا الحد الأدنى من المسارات والنتائج اللازمة.
4. لا يوسع الفحص بعد دليل كافٍ؛ يوسع فقط عند تغير revision/nطاق أو وجود خطر غير مغلق.
5. لا يتجاوز فحص الأمن أو المالية أو التسليم اللازم بحجة توفير السياق.

## اختبار توجيه مختصر

| الحالة | القرار الذكي | ما تم تجنبه |
|---|---|---|
| شعار أو tooltip محلي في Baseer | `LOCAL`: registry + مالك الواجهة + اختبار واجهة محدد | إعادة خريطة ERP أو فريق تسليم أو بحث خارجي |
| تعديل attendance يمس العقد أو الصلاحيات | `ARCHITECTURAL`: المعماريون + البناء وخبير ERP المناسب، ثم اختبار HTTP المالك | وكيل واجهة أو أجنتان يقرآن الوثائق نفسها |
| مرشح إصدار | فريق التسليم بعد دليل البناء ومعرف المرجع | بناء خريطة جديدة أو إعادة اختبارات لا يمسها المرشح |

الاختبار لا يضع سقفاً ثابتاً لعدد الأوامر أو الأجنتات؛ معيار النجاح هو أن كل خطوة جديدة تجيب سؤالاً لم تجبه أدلة البصمة الحالية.

## سجل موجز مطلوب للعمل المركب

```text
Fingerprint:
Reused reference/evidence:
Selected skills and why:
Delegated owners and non-overlap:
Commands/reads avoided by reuse:
Final evidence and next owner:
```

هذا السجل جزء من مدخل البناء الحي أو سجل أثر التغيير، وليس قاعدة بيانات جديدة أو مخرجات مطولة للمستخدم.
