# بطاقة أثر — صافي حركة الخزائن وسجلات الالتزامات والإدارة

**المعرف:** `BASEER-IMPACT-2026-09-05-TREASURY-PERIOD-NET-ADMIN-REGISTERS`
**المرجع:** `BASEER-ARCH v1.0`
**التصنيف:** `ARCHITECTURAL`
**المالك:** Finance & Accounting، وPlatform Identity & Administration
**آخر تحقق قبل البناء:** `0f806d2f64bd9ed6d16d310fd4683b445c4b2288`

## الهدف والنطاق

1. استبدال الرصيد التراكمي الظاهر في ملخص الخزائن وبطاقات الخزائن بمؤشر فترة صريح: `صافي حركة المدة = الوارد - الصادر`، يعرض للمستخدم باسم «رصيد إقفال المدة» بلا نص معادلة منفصل.
2. تحويل قائمة الالتزامات المتكررة وسجل السداد إلى جداول Baseer ذات رؤوس أعمدة ثابتة وعرض جوال مقروء.
3. إظهار شعار الشركة المعتمد داخل بطاقة الشركة، مع بديل حرف الاسم فقط إذا تعذر تحميله.
4. جعل أرشفة الشركة وقفل مراجعة الترحيل أزرار خطر صغيرة متجاورة، بلا حقول أو حاويات تحذيرية إضافية.

## الحقيقة والعقود والرقابة

- `TreasuryService` هو المصدر الوحيد لـ`net`؛ لا تحسب React الوارد ناقص الصادر. يعاد `net` لكل خزينة ولكامل المساحة؛ يبقى `balanceAsOf` و`openingBalance` في العقد للتفاصيل فقط، ولا يعاد تعريف أي منهما أو تعديل قيد.
- قيمة «رصيد إقفال المدة» في الملخص وبطاقة كل خزينة هي **صافي حركة الفترة** وليست الرصيد المحاسبي التراكمي؛ لا يظهر نص معادلة منفصل في الواجهة.
- سجل الالتزام وسجل السداد يستخدمان القراءة الخادمية المحدودة القائمة؛ لا تحميل تاريخ إضافي ولا تغيير في الترحيل أو السداد.
- بطاقة الشركة تستدعي endpoint الشعار الموثق نفسه وبـBearer session؛ لا يوضع مسار التخزين أو blob في عقد الشركة أو DOM.
- الأزرار القائمة تبقي أوامر الأرشفة/القفل الخادمية وتدقيقها كما هي؛ التغيير تنسيقي فقط.

## G0–G4

- **المسار المباشر:** تمديد العرض من مصدر `net` الخادمي القائم، واستعمال `BaseerDataGridField` و`BaseerButton` وloader الشعار الموجود؛ لا اعتماد جديد ولا API جديد.
- **السعة:** قراءات السداد والالتزامات تظل صفوفاً خادمية محدودة كما هي؛ لا pagination أو query إضافي في هذه الشريحة.
- **الرقابة المالية:** لا تصفير اصطناعي ولا تغيير رصيد تراكمي؛ المؤشر الجديد يعرض صافي الفترة فقط لكل خزينة ويُختبر على قيم موجبة وسالبة.
- **التجربة:** الجداول تحمل caption وheaders، وتتحول إلى عرض حقول مسمى على الشاشات الضيقة من المكوّن المركزي. أزرار الخطر تحتفظ بنص ظاهر ولا تعتمد على اللون وحده.
- **التراجع:** commit واحد يعيد العرض والعقد المضاف؛ لا migration ولا تعديل بيانات حية أو أسرار.

## معايير القبول

- ملخص الخزائن وبطاقات الخزائن لا تعرض رصيدًا تراكميًا أو «رصيد الافتتاح»، وتعرض «رصيد إقفال المدة» المطابق خادمياً لـ`net`.
- الالتزامات المتكررة وسجل السداد يظهران كجداول برؤوس عربية/إنجليزية واضحة، ويظلان قابلين للاستخدام على الجوال.
- تظهر صورة الشعار في بطاقة شركة لها `logoFileMetadataId` صالح، ويظل بديل الحرف عند فشل التحميل.
- يظهر إجراءا الأرشفة وقفل المراجعة معاً كأزرار خطر صغيرة، ولا يتغير أمرهما أو صلاحياتهما.
