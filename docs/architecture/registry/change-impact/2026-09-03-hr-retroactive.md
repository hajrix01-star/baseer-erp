# بطاقة الأثر — صلاحية HR للأثر الرجعي

- **المعرف:** `BASEER-IMPACT-2026-09-03-HR-RETROACTIVE`
- **التصنيف:** `ARCHITECTURAL` تحت `BASEER-ARCH v1.0`
- **النطاق:** الموارد البشرية، الموظفون، التعويضات، التفويض وسجل التدقيق.
- **القرار:** مالك الشركة ومديرها يستطيعان تسجيل توظيف قديم وأول راتب يبدأ في شهر سابق. الأدوار الأخرى تحتاج الصلاحيات الأساسية فقط ولا تأخذ قدرة الأثر الرجعي تلقائياً.
- **مصدر الحقيقة:** الخادم يحسم التفويض وتاريخ العمل. الواجهة لا تضيف عقداً أو قيمة صلاحية يثق بها الخادم.
- **الحماية المحاسبية:** لا تعدّل العملية مسيراً معتمداً أو مدفوعاً ولا تعيد احتسابه؛ حارس الاتفاقات المعتمد يبقى فعالاً.
- **الملفات المتوقعة:** كتالوج الصلاحيات، `HrController`، `HrPayrollService`، نافذتا تهيئة الموظف/الراتب أو مكوّن الصلاحية، واختبارات HR.
- **البيانات والمخطط:** لا migration ولا تبديل بيانات حية. سجل التدقيق القائم يحفظ العملية والفاعل وموعد السريان.
- **مخاطر القبول:** منع غير المخول، قبول المالك/المدير، منع تغيير مسير الموظف المعتمد، وفحص تاريخ قديم من الواجهة وAPI.
- **حالة التنفيذ:** مكتمل محلياً؛ تحققت بوابات العقود والصلاحيات والمعمارية وbuild الواجهة، إضافة إلى تحقق HTTP وتهيئة الموظف ودورة HR. لا يوجد نشر ضمن هذه البطاقة.
