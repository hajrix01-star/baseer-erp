# بطاقة أثر — سجل تقييمات كامل وتصميم لوحة السمعة

**المعرف:** `BASEER-IMPACT-2026-09-06-FULL-REVIEW-HISTORY-AND-DESIGN`
**المرجع:** `BASEER-ARCH v1.0` / `ADR-MKT-003` / `ADR-MKT-004`
**التصنيف:** `ARCHITECTURAL`
**الحالة:** G0–G7 مكتمل محلياً؛ G8 مرشح مراجعة وتسليم بعد CI.

## عقد البناء

- **المستخدم:** مدير الشركة الذي يريد قراءة سجل Google Business كاملاً وفهم
  التقييمات التي تتطلب متابعة من صفحة واحدة عربية أولاً.
- **القبول:** زر مزامنة وحيد، لا حذف زمني للسجل، صفحة أولى من 50 صفاً مع
  cursor، فلاتر خادمية، مؤشرات وتوزيع نجوم خادميان، عربي/إنجليزي وRTL/LTR
  وجوال/سطح مكتب، ولا نشر Google.
- **المسار المباشر:** تعديل المالك القائم للحقائق والواجهة؛ لا نقل بيانات من
  Baseer السابق ولا مكتبة جديدة ولا صفحة ربط ثانية.
- **خارج النطاق:** OAuth وAds وGA4 والنشر والردود التلقائية والحقائق المالية.

## الأثر وملكية البيانات

| الطبقة | الأثر |

| `MarketingGoogleBusinessReviewsService` | إلغاء تنظيف 90 يوم، وإضافة فلاتر/توزيع خادميين مع استمرار lease وcursor. |
| contracts/controller | عقد قراءة محدود بالفلاتر الاختيارية؛ لا secret أو raw payload. |
| web reputation | إعادة تركيب العرض بالمكونات المركزية: سياق، مؤشرات، تحليل، توزيع، فلاتر، سجل. |
| Prisma | لا migration: الجدول والفهارس الحالية تكفي لقراءة `reviewUpdatedAt` وrating/reply. |

## السعة والاختبارات

- 5,000 fact كحد القراءة الحالية لكل موقع؛ 50 صفاً لكل صفحة مستخدم.
- منع التزامن موجود: advisory lock وlease 30 دقيقة؛ لا يزيد هذا التغيير egress.
- نجح محلياً: policy verifier للحفظ التاريخي والفلاتر والتوزيع، contracts/API/web
  checks وbuild، وحراس architecture/permissions/authorization/transport/Nest والواجهة.
- أضيف اختبار E2E للفلترة والسجل والتوزيع؛ لم يشغّل محلياً لأن منفذ Playwright
  `5191` محجوز بجلسة تطوير قائمة، لذلك هو بوابة CI النظيفة قبل G8.
