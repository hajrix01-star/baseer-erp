# بطاقة الأثر — مطابقة صلاحيات اختبار AI Gate B

- **المعرف:** `BASEER-IMPACT-2026-09-03-AI-GATE-B-HTTP-FIXTURE-CAPABILITIES`
- **التصنيف:** `CONTROLLED` تحت `BASEER-ARCH v1.0`؛ النطاق محصور في fixture تحقق HTTP ومرجع AI الحالي.
- **المشكلة المثبتة:** مهارة `marketing.performance_analyst` تعلن صراحةً حاجتها إلى `marketing.insights.read` إضافةً إلى `platform.ai.use`، بينما fixture المستخدم المخول يضيف الصلاحية الثانية فقط. لذلك يرفض الحارس الخادمي الطلب بـ403 كما يجب.
- **القرار:** يضيف الاختبار الصلاحيتين المعلنتين للمستخدم المخول فقط، ويثبت سبب الحجب الفعلي للمهارة التجريبية: تنفيذ الموفر معطل. تستمر الخدمة في طلب صلاحية المنصة داخلياً، بينما يعرض عقد الاستجابة متطلبات المهارة الإضافية فقط. يبقى المستخدم المحدود بلا صلاحيات، وتبقى شركة أخرى مرفوضة؛ لا تتغير صلاحيات الإنتاج أو العقود أو قاعدة البيانات.

## البوابات والتحقق

- **G0–G3:** يثبت الاختبار تفويضاً دقيقاً وفق كتالوج المهارة، بلا تغيير API أو schema أو سعة أو اعتماد.
- **G4:** لا أثر مرئي.
- **G5–G7:** يعاد `verify:ai-gate-b-http` في CI؛ القبول يتطلب نجاح المخول، ورفض المحدود والشركة الأخرى، واستمرار حدود rate-limit وحفظ receipts.
- **التراجع:** revert للـcommit؛ لا أثر على Hostinger أو DNS أو بيانات حية.
